RAASITH MOBILE POS v2.6 - PC DATA STORAGE

New feature:
1. Data & Backup -> Choose Data Store Location.
2. A Security Verification window appears.
3. Management password: 1302513025
4. After correct password, choose any writable folder on this PC.
5. The app creates/uses SF SMART POS SYSTEM_Data.json in that folder.
6. Stock, sales, customers, companies and users are automatically saved to the selected folder after changes.
7. The selected folder permission is remembered by Chrome/Edge for this app.

Important:
- This uses the browser File System Access API. Use a recent Chrome or Edge.
- The app still uses browser storage as a working cache; the selected PC folder is the permanent data file location and is automatically synchronized.
- Keep a backup copy of SF SMART POS SYSTEM_Data.json on another drive/cloud.
