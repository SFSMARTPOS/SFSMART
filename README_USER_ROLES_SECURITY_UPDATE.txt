SF SMART POS v19 — User Role & Security Update

Changes in this build:
1. User Management now has Edit Role for each user.
2. Role choices are Owner, Manager, Normal User.
3. Legacy Admin is migrated to Owner; legacy Cashier is migrated to Normal User.
4. Owner and Manager users require management-password verification only for User Management and Shop Settings.
5. For Owner and Manager, other existing security prompts are bypassed.
6. Normal User keeps the existing security-verification behavior.
7. Technician Profile follows the role rule: Owner/Manager can open it without a prompt; Normal User keeps the existing security prompt.
8. Existing app functions and layout are otherwise preserved.
