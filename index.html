💾 Data Backup & Load

Simple backup system. Backup Data saves the complete SF Smart POS database into one JSON file. Load Backup Data restores the complete database from that file.

The backup includes shop logo, shop name, address, phone, users, companies, stock, sales, customers, credit bills, credit payments, Temporary Accounts, settings and all other application data.

Important: Loading a backup replaces the current application data with the selected backup, so the old data from that backup comes back exactly as saved.
