SF SMART POS v19 - Repair History / Repair Bill / Token Barcode Update

Base: SF SMART POS v19 Technician Profile & Effective Commission

Changes:
1. Removed the My Profit column from Repair History & Cost Analysis.
2. Removed My Profit fields from the Repair History Excel export; My Profit remains in the separate My Profit Dashboard.
3. When MARK REPAIR FINISHED is pressed, the repair is saved as Finished first and then a thermal 80mm Repair Service Invoice opens automatically for printing. The print design follows the existing POS bill style.
4. The Repair Receiving Token now has a long, locally generated Code 39 barcode at the bottom containing the repair token.
5. Service worker cache version bumped to force the browser to load the updated files.
