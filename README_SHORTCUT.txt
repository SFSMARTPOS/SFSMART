RAASITH MOBILE - DESKTOP SHORTCUT

To create a Windows desktop shortcut with the RAASITH MOBILE logo:
1. Extract this folder to any location.
2. Open the rasith_v18 folder.
3. Double-click: Create_Desktop_Shortcut.bat
4. A desktop shortcut named "RAASITH MOBILE" will be created.
5. Double-click that shortcut to open the POS app in an app-style Chrome/Edge window.

This method is designed for local/offline use and does not depend on Chrome's "Create shortcut..." menu.


Multi-company data is supported in v2.2: each company has separate stock, sales, customers and reports.
