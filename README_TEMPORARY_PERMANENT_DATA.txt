SF SMART POS SYSTEM - Temporary Accounts Permanent Data

Temporary Accounts data is stored inside each company's main database (tempAccounts).

Therefore:
1. Temporary Sales, Credit Bills and Credit Payments are saved to the permanent PC data file:
   SF SMART POS SYSTEM_Data.json
2. Backup Data includes Temporary Accounts automatically.
3. Load Old Data restores Temporary Accounts automatically.
4. Restore From Store / recovery copy restores Temporary Accounts automatically.
5. Temporary Accounts never changes Stock.

After connecting a PC data folder in Data & Backup, every Temporary Accounts save/update/delete/payment
is also written to the permanent PC data file automatically.
