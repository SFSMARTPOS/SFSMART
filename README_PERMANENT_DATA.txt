SF SMART POS SYSTEM — PERMANENT PC DATA PROTECTION v3.24

FIRST TIME SETUP
1. Login.
2. Open Data & Backup.
3. Choose Data Store Location.
4. Create/select a dedicated folder such as D:\RaasithMobileData.
5. Allow Chrome permission.
6. The app creates SF SMART POS SYSTEM_Data.json.

AUTOMATIC PROTECTION
- Stock, sales, customers, credit, companies and users are automatically saved to the PC folder.
- A second recovery copy, SF SMART POS SYSTEM_Data_Backup.json, is maintained in the same folder.

IF CHROME DATA IS CLEARED
- Chrome History alone does not remove the PC-folder database.
- If Chrome Cookies/Site Data was also cleared, the saved folder permission may be forgotten.
- Open Data & Backup and choose the same PC folder again.
- Or use Recover From JSON File and select SF SMART POS SYSTEM_Data.json / the backup JSON.

IMPORTANT
A browser cannot access a PC folder after its permission is completely removed without asking the user to reconnect it. This is a Chrome security rule. The database itself remains in the PC folder.
