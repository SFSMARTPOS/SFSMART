SF SMART POS - SIMPLE DATA BACKUP

Data & Backup now has only two actions:
1. Backup Data - exports one complete JSON backup containing shop logo/details, users, companies, stock, sales, customers, credit bills, credit payments, Temporary Accounts, categories and application settings.
2. Load Backup Data - imports the selected complete JSON backup and replaces the current application data with the backup contents. No PC folder selection is required.

Temporary Accounts are included in the same backup and are restored with the rest of the database.
